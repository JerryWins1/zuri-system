💰 Finance — one-page guide

Kelvin's daily, weekly and monthly money routine in Zuri · v3 · 7 October 2026
WhenWhat to do in Zuri
Every dayMoney → 💵 Today: read the red/orange boxes. Then 📋 Bills → Pay run → 🔄 Build today's list: every bill due and every salary whose day it is. Send each in M-Pesa, tap ✅ Sent, type the code. Record every payment out: ✍️ Record → Money out — paste the M-Pesa message → Read the message → check → Save.
Every Friday💵 Count the cash (bank app + M-Pesa balance) → 📊 Report → Copy for WhatsApp → paste into the partners' group.
1st of the month📋 Bills → Copy last month's bills → change any amount that's different.
Monthly🏦 Statements: bring in each bank and M-Pesa statement (Excel, CSV or the M-Pesa PDF). Then Sort them. Tick always to teach Zuri. Then read Profit by month.

The money rules

Cash after bills below zero? Stop. Tell Jerry the same day, before paying anything else.
M-Pesa float below target? Flag it today — don't wait for Friday.
No invoice, no payment. No receipt? Choose "No — chase it" so it shows on the list until it's found.

Where things are

👥 Customers → Who paid
Paid, late, part-paid, not due yet. 📞 and 💬 buttons for late payers.
👥 Customers → Next 30 days
The cash forecast. Add one-off money (like funding from Jerry) to see the effect.
✅ Tasks → WhatsApp nudges
Each morning: tap Open WhatsApp → send → Mark sent.
🏦 Statements → Bring in a file
Customer list from Billnasi (Excel), when asked.
👥 Admin → Staff & pay
Everyone Zuri pays: M-Pesa number, salary, pay day. Feeds the Pay run. Finance and partners only.
📋 Bills → ✏️ Pay to
Put the paybill and account (or phone) on each bill, so the Pay run knows where the money goes.
