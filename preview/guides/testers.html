🧪 Zuri Tester Checklist

Tick each line as you test it · write what was wrong on the back · v5 · 10 October 2026

Everyone — first

  • ☐ Watch “What Zuri is” (5 min)
    Me → 🎓 Learn → ⭐ What Zuri is. Sound on.
  • ☐ Add Zuri to your phone's home screen
    In Chrome: ⋮ → Add to Home screen. Open it from the icon.
  • ☐ Find your tabs and open each one
    The tabs are at the bottom. Open every one and read what is there.
  • ☐ Tick one task as done, and write a note on it
    Tasks → My day → tick a box → 💬 Notes → type → Add.
  • ☐ Give a teammate a task
    Tasks → ＋ Add a task → write it → choose the person → Add task. Ask them if it arrived.
  • ☐ Try it with no signal
    Turn on airplane mode. Tick a task or add a note. Turn signal back on — the yellow badge should clear.
  • ☐ Switch to Light and back
    Me → Screen → ☀️ Light. Which is easier to read outside?
  • ☐ Snap a receipt and save it
    Me → 📸 Snap a receipt (or Tasks → My day) → 📸 Take a photo → check the boxes → choose what it was for → ✅ Save. Find it in Me → 🧾 My receipts.
  • ☐ Paste an M-Pesa message as a receipt
    📸 Snap a receipt → 📩 Paste M-Pesa message → paste one of your own old messages → Read the message → check → Save. Try a Paybill, a till and a Send money message.
  • ☐ Save a receipt with no signal
    Airplane mode on → snap a receipt → it says “No signal — type it” → type the boxes → Save → airplane mode off → the yellow badge clears.

Field techs

  • ☐ Open a job, call the customer, open the map
    Jobs → tap a job → 📞 Call → 🗺️ Open map.
  • ☐ Start a job
    In the job: ▶ I'm starting now. The office should see it change.
  • ☐ Finish a job with a cash payment
    Tap what you found and what you did → 💵 Cash → amount → ✅ Job finished.
  • ☐ Finish a job with an M-Pesa payment
    Same, but 📱 M-Pesa and type a code like UJ7K2M9PQR.
  • ☐ Add a photo to a job
    In the job: 📷 Add photo → take a picture. Does it show?
  • ☐ Add a part you used
    Parts & equipment → item, serial, qty → Add.
  • ☐ Drop a map pin (outside)
    In the job: 📍 Drop pin here. Does it ask again if the signal is weak?
  • ☐ Log a new job yourself
    Jobs → ＋ Log a job → describe it → Save.
  • ☐ Snap a receipt on a job
    Open a job → 🧾 Spent money on this job? → 📸 Snap the receipt → photo → check → Save. You come back to the job.
  • ☐ Chase a missing receipt
    Save one with “No receipt yet — chase it”. Later: Me → 🧾 My receipts → 📸 Snap it now → photo. The ❌ turns to 📷.
  • ☐ Sort your jobs nearest-first
    Jobs → 📍 Nearest first → allow location. Each job shows how far it is. Then switch location off for the browser and try again — the list should still work (urgent first, then by day).
  • ☐ Save a customer's pin at “I'm starting now”
    Open a job whose customer has no pin → ▶ I'm starting now → Zuri offers “Save this location as the pin?” → Yes (outside). Indoors it should warn that the location is rough.

Call center

  • ☐ Work a payment follow-up: No answer
    Jobs → a Payment follow-up → 📵 No answer. It should come back tomorrow.
  • ☐ Record a promise to pay
    Another follow-up → 🤝 Will pay → pick a day → Save.
  • ☐ Record “says paid” and “wants to stop”
    ✅ Says paid on one; ✋ Wants to stop on another.
  • ☐ Send today's after-cutoff message by text and by WhatsApp
    In a follow-up: read which step it is (day 1, 3, 7, 14 or 30), then 📩 Text it and 💬 WhatsApp it. (Send them to yourself in training.)
  • ☐ Make a fault job from a customer call
    Jobs → ＋ New job → find the customer → Fault → describe → tech + day → Save job.
  • ☐ Tell the tech on WhatsApp
    In the job you made: 💬 Tell … on WhatsApp.
  • ☐ Find a customer by phone number
    Customers → type the number → open them → check Payments and Jobs.
  • ☐ Add a new customer
    Customers → ＋ New customer → fill in → Save.
  • ☐ Send today's texts from one list
    Jobs → 📩 Today's texts → read the step → 📩 Text (send it to your own number in training) → Next. Skip one. Does the count go up? Does the job show the note?
  • ☐ Fault call from a customer whose package expired
    Jobs → ＋ New job → find a customer whose service ran out → Fault. A warning says “probably not a fault”. Tap 💳 Turn this into a payment follow-up — no tech is sent.
  • ☐ Three fault calls from one area = an outage
    Make three fault jobs in the same area within a few minutes. A red “Possible outage” card should appear on Jobs, and one task for technical.

Finance

  • ☐ Read Cash today and the warnings
    Money → 💵 Today. What is each red or orange box telling you?
  • ☐ Do a cash count
    Money → Count the cash → bank + M-Pesa → Save.
  • ☐ Record an expense from a pasted M-Pesa message
    Money → Record → Money out → paste a message → Read the message → Save.
  • ☐ Record hotspot money in
    Money → Record → Money in → Hotspot → amount → Save.
  • ☐ Pay part of a bill
    Money → Bills → Pay → smaller amount → Bank → Pay.
  • ☐ Copy last month's bills (next month)
    Bills → → (next month) → Copy last month's bills.
  • ☐ Sort five transactions, one with “always”
    Money → Statements → Sort them → choose a category; tick always on one.
  • ☐ Read Profit by month
    Money → Statements → Profit by month. Does last month make sense?
  • ☐ Chase a late payer from Who paid
    Money → Customers → Who paid → Late → 📞 or 💬.
  • ☐ Copy the Friday report
    Money → Report → Copy for WhatsApp → paste it somewhere.
  • ☐ Add a staff member with an M-Pesa number
    Money → 📋 Bills → Staff & pay → ＋ Add → name, M-Pesa number, salary, pay day → Save.
  • ☐ Build the pay run and record one payment
    Money → Bills → Pay run → 🔄 Build today's list → ✅ Sent on one → code → Record it.
  • ☐ Send one morning nudge
    Tasks → WhatsApp nudges → Open WhatsApp → send to yourself → Mark sent.
  • ☐ See a repeat warning and a statement match
    Money → Record → 📸 Snap a receipt → paste an M-Pesa message twice (save the first). The second time it says “Already recorded”. A code that is in an imported statement says “matched”.
  • ☐ Open a receipt photo from Money out
    Money → Record → Money out → tap 📷 on an expense.
  • ☐ Read “Receipts this week” in the Friday report
    Money → 📊 Report: total by category, top 5, how many have receipts, and the missing list with who recorded each.
  • ☐ Send the Friday report without gathering anything
    Money → 📊 Report: money, service, follow-ups, the team, receipts, payments waiting and the manager's summary. Copy for WhatsApp → paste. Open 🖨 Printable view.
  • ☐ Pay a bill — it waits for a second person
    Money → Bills → 💸 Pay → record it. The bill shows “⏳ waiting for a second OK” and is not counted as paid yet.
  • ☐ Try to approve your own payment
    Money → Bills → 👥 Approvals → “You recorded — waiting for someone else”. There is no Approve button; the database refuses it too.
  • ☐ Approve someone else's payment (and confirm a field tech's receipt)
    👥 Approvals → Waiting for your OK → ✅ Approve. Check the bill now counts it as paid. Decline one with a reason.

Partners & admin

  • ☐ Read Home: what needs attention, lowest cash day
    Home → Needs attention → tap one. Find “Lowest in next 30 days”.
  • ☐ Switch on a new staff member
    Me → ⚙️ Admin → People → role, area, On → Save.
  • ☐ Hide a field from field techs
    Admin → Who sees what → untick something for Field tech → check as a tech.
  • ☐ Add a custom customer field
    Admin → Custom fields → add one → see it on a customer.
  • ☐ Add Zuri C as an area
    Admin → Areas → add → does it appear in the area picker?
  • ☐ Run the manager and read the log
    Tasks → 🤖 Run the manager now → Manager log.
  • ☐ Bring in a customer file
    Me → 📥 Bring in a file → the Billnasi Excel export → check the counts.
  • ☐ Switch “Read receipts with AI” on and off
    Me → ⚙️ Admin → Settings → On → snap a receipt (the boxes fill) → Settings → Off → snap again (it asks you to type).
  • ☐ Approve a payment Kelvin recorded
    Home → 👥 payments waiting for your OK → ✅ Approve. Then Money → Bills: the bill counts it as paid.
  • ☐ Find the two-person rule and its amount
    Me → ⚙️ Admin → Settings → 👥 Two people for money out. Leave it On (0 = every payment).
  • ☐ Say yes to an outage notice, then close the outage
    After three fault calls from one area: Home → the 📡 outage card → change the words → ✅ Yes → 📋 Copy (Zuri never sends it). Then ✅ Service is back.

📈 Projects (finance & partners)

  • ☐ Watch the 📈 Projects videos
    Me → 🎓 Learn → 📈 Projects → ▶ Play all (about 30 min; ✕ stops).
  • ☐ Plan a new area and read when it pays back
    Money → 📈 Projects → ＋ New project → fill A start-up, B running costs, C customers (tap Use it for Zuri A's bill) → read The answer: break-even and payback.
  • ☐ Read the what-ifs and the month table
    In a project: What if? (low take-up, bill ±10%) and Month by month (12 / 24 / 36 / 60).
  • ☐ Compare two areas, and try a loan
    Projects → ⚖️ Compare. Then in Narok (example): D · A loan? — untick and tick, watch the payback move.
  • ☐ Copy a project for WhatsApp and open the one-page report
    In a project: 📋 Copy for WhatsApp (paste it in a note) → 🖨 One-page report.
  • ☐ Say “we're doing it” — and approve it as the second person
    In a plan: ✅ We're doing it → Send for the second OK. A different finance person or partner taps ✅ Approve (in practice: 🎭 switch).
  • ☐ Update a live project's forecast, with a reason
    Suswa (example) → 📝 Forecast → change a number → 💾 Save the forecast → write why. Find it in 📜 Log.
  • ☐ Confirm last month's actuals and read the variance
    Suswa (example) → tap the orange “not confirmed” line → save customers, then money. Read the coloured box, the three-line chart and the table.
  • ☐ Tag spending to a project
    Money out → Area: Zuri D → the Project box picks 📈 Suswa by itself → save → find it in Suswa's Actuals.
  • ☐ Record an actual with no signal
    Airplane mode on → Suswa → ＋ Record actuals → Save → it says “saved on this phone” → airplane mode off → it sends.
